# Attribution

This project is a derivative port of [Pale Fire](https://github.com/matklad/pale-fire) by matklad. Pale Fire is distributed under GNU GPL v3 and describes itself as a VS Code port of `emacs-zenburn`.

Zenburn was created and maintained by multiple contributors, including Bozhidar Batsov's [emacs-zenburn](https://github.com/bbatsov/zenburn-emacs). This port preserves Pale Fire's generated palettes and semantic role assignments while translating its editor interface and syntax model to Zed's theme schema.

Microsoft's VS Code default themes were consulted only as a reference for broad fallback coverage and semantic-token structure. Their colors and theme identity are not included in this work.
